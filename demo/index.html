cron-calendar

Один файл, ноль зависимостей. Сетка ячеек — визуальный редактор cron-выражения, обычное текстовое поле рядом остаётся источником правды.

Вариант по умолчанию: неделя с воскресенья, сетка видна всегда

событие change ещё не приходило
Клик по ячейке выбирает значение, повторный — снимает. Пустое поле = *. Рядом с каждой сеткой можно вписать выражение руками — оно нормализуется на выходе.

Неделя с понедельника (5+2) и выпадающая панель по фокусу

событие change ещё не приходило
mode="popover" прячет сетку: она выпадает при фокусе на поле, закрывается по клику вне и Escape. week-start="mon" ставит понедельник первым.

Валидация дат

31 при фев,июл — жёлтый: в феврале день пропустится
Красный — такого числа не бывает ни в одном выбранном месяце (0 0 31 2 *). Жёлтый — не бывает в части месяцев.

Локализация: locale="en" (названия — из Intl, неделя — из CLDR)

неделя с воскресенья (en-US по CLDR), подписи и подсказки по-английски
Названия месяцев и дней приходят из Intl.DateTimeFormat, первый день недели — из Intl.Locale.weekInfo при week-start="auto". Незнакомый язык всё равно получает свои названия, а фразы — английские.

Список ближайших запусков: next-runs

сверху run-format по умолчанию (без дня недели), снизу — с днём недели
next-runs="6" — сколько строк показать (по умолчанию 5), timezone — IANA-зона для расчёта и подписи, run-format — состав строки: weekday, day, month, year, time. Правило дня как в cron: если ограничены и день месяца, и день недели — достаточно совпадения любого.

Языки пакета: ru, en, de, fr, es, it, pt, pl, tr, zh

переключи язык — подписи и подсказки меняются, названия месяцев приходят из Intl
Переводятся подписи полей, подсказки и заголовок списка запусков; месяцы и дни недели — из Intl, поэтому работают и для языков вне пакета.

Перечисление на ничьей — флаг компонента

сверху флаг включён (по умолчанию), снизу — enumeration="off"
При равной длине токена включённый флаг оставляет перечисление (2,4,6,10), выключенный отдаёт форму с шагом (2-6/2,10).

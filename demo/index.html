cron-calendar

Один файл, ноль зависимостей. Сетка ячеек — визуальный редактор cron-выражения, обычное текстовое поле рядом остаётся источником правды.

Вариант по умолчанию: неделя с воскресенья, сетка видна всегда

событие change ещё не приходило
Клик по ячейке выбирает значение, повторный — снимает. Пустое поле = *. Рядом с каждой сеткой можно вписать выражение руками — оно нормализуется на выходе.

Неделя с понедельника (5+2) и выпадающая панель по фокусу

событие change ещё не приходило
mode="popover" прячет сетку: она выпадает при фокусе на поле, закрывается по клику вне и Escape. week-start="mon" ставит понедельник первым.

Валидация дат

31 при фев,июл — жёлтый: в феврале день пропустится
Красный — такого числа не бывает ни в одном выбранном месяце (0 0 31 2 *). Жёлтый — не бывает в части месяцев.

Перечисление на ничьей — флаг компонента

сверху флаг включён (по умолчанию), снизу — enumeration="off"
При равной длине токена включённый флаг оставляет перечисление (2,4,6,10), выключенный отдаёт форму с шагом (2-6/2,10).
